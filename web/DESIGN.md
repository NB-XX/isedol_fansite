# 设计说明

## 🎨 视觉设计

### 整体风格

- **现代简约**: 干净的界面，突出内容
- **卡片式设计**: 清晰的信息层级
- **渐变背景**: 柔和的视觉体验
- **微交互**: 丰富的悬停和点击效果

### 颜色方案

```css
主色调 (Primary): #00C73C  /* Naver 绿 */
次要色 (Secondary): #FF6B6B  /* 强调红 */
背景色: linear-gradient(to bottom right, #F9FAFB, #F3F4F6)
文字色: #111827 (深灰)
次要文字: #6B7280 (中灰)
边框色: #E5E7EB (浅灰)
```

### 字体

- **标题**: 系统默认 Sans-serif，加粗
- **正文**: 系统默认 Sans-serif，常规
- **代码**: Monospace

## ✨ 动画效果

### 1. 彩虹外发光

```css
@keyframes rainbow {
  0%, 100%: 红色光晕
  16%: 橙色光晕
  33%: 黄色光晕
  50%: 绿色光晕
  66%: 蓝色光晕
  83%: 紫色光晕
}

持续时间: 3秒
循环: 无限
```

### 2. 加载动画

```css
旋转的圆环
颜色: 主色调
大小: 48px
位置: 居中
```

### 3. 悬停效果

```css
卡片:
- transform: scale(1.01)
- box-shadow: 加深

头像:
- transform: scale(1.05)
- 过渡: 300ms

按钮:
- background: 加深
- 过渡: 200ms
```

### 4. 页面过渡

```css
淡入淡出
持续时间: 300ms
缓动函数: ease-in-out
```

## 🎯 交互设计

### 主播头像

```
状态: 默认
- 显示头像和名字
- 灰色边框

状态: 直播中
- 彩虹外发光
- 红色 LIVE 标签
- 头像底部红色条

交互: 悬停
- 放大 5%
- 名字变为主色调

交互: 点击
- 打开模态框
- 显示详细信息
```

### 文章卡片

```
状态: 默认
- 白色背景
- 轻微阴影

交互: 悬停
- 阴影加深
- 轻微放大
- 标题变色

交互: 点击标题
- 高亮效果
- 可选: 展开/收起

交互: 点击"查看原文"
- 新标签页打开
- 外部链接图标
```

### 模态框

```
打开动画:
- 背景淡入
- 模态框从中心放大淡入

关闭方式:
1. 点击关闭按钮
2. 点击背景
3. 按 ESC 键

关闭动画:
- 模态框缩小淡出
- 背景淡出
```

## 📱 移动端优化

### 触摸优化

```css
/* 增大点击区域 */
.touch-target {
  min-height: 44px;
  min-width: 44px;
}

/* 禁用长按菜单 */
.no-context-menu {
  -webkit-touch-callout: none;
}

/* 平滑滚动 */
.smooth-scroll {
  -webkit-overflow-scrolling: touch;
}
```

### 布局调整

```
移动端:
- 主播头像更大 (更易点击)
- 文章卡片内边距减小
- 字体稍大 (易读性)
- 间距减小 (节省空间)
```

## 🎨 主题定制

### 自定义颜色

编辑 `tailwind.config.js`:

```javascript
theme: {
  extend: {
    colors: {
      primary: '#00C73C',    // 主色调
      secondary: '#FF6B6B',  // 次要色
      dark: '#1a1a1a',       // 深色
      // 添加更多颜色...
    }
  }
}
```

### 自定义动画

```javascript
animation: {
  'rainbow': 'rainbow 3s linear infinite',
  'pulse-slow': 'pulse 3s cubic-bezier(0.4, 0, 0.6, 1) infinite',
  // 添加更多动画...
}
```

### 自定义断点

```javascript
screens: {
  'xs': '475px',
  'sm': '640px',
  'md': '768px',
  'lg': '1024px',
  'xl': '1280px',
  '2xl': '1536px',
}
```
